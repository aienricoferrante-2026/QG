⛔ Disabled
La webapp non gestisce allegati. Default per BP, CdG, SGI (no documenti cliente).
💽 In-app (Supabase)
Allegati nel bucket Supabase della webapp. Semplice, veloce. Limite 25 MB.
☁️ SharePoint/OneDrive
Default consigliato. Cartelle per cliente, link condivisi, backup Microsoft. Niente doppio storage.
Customer upload-only: per ogni webapp puoi attivare il flag che permette ai clienti di SOLO CARICARE file (non leggere/cancellare). Esempio Q-WORK: il cliente carica il documento richiesto, il commerciale lo vede, ma il cliente non può sbirciare nella cartella di altri.
